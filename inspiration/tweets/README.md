# Local story-tweet archive

One Markdown file per verified X post that contains story prose or a story excerpt. Each file records the canonical tweet URL, account, post date when shown, date captured, and the visible post text copied from the signed-in browser. Announcements, prompts, commentary, art, and animation posts are excluded. Replies, quoted posts, and attached media are not included unless saved as their own verified story post.

An explicitly requested north-star essay may be cataloged here as a reference even if it is not a story excerpt. Keep its source link and project-authored use note in the tracked record. Keep the full copied text local unless its permission explicitly covers publication; note when a local capture is omitted from Git.

**Permission status:** The project owner reports having received permission to archive the tweets collected in this folder. This records permission to archive; permission to publish, redistribute, or adapt the copied text or media is not documented here.
