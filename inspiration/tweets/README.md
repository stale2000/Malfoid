# Local story-tweet archive

One Markdown file per verified X post that contains story prose or a story excerpt. Each file records the canonical tweet URL, account, post date when shown, date captured, and the visible post text copied from the signed-in browser. Announcements, prompts, commentary, art, and animation posts are excluded. Replies, quoted posts, and attached media are not included unless saved as their own verified story post. This folder is local research; do not commit or redistribute copied text or media without permission.
