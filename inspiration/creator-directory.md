## Finding, downloading, and updating references

This is a link directory, not a mirror of the creators' works. Open the linked profile and locate the specific post or work that informed an idea. Record that direct work link and the date checked in [the source catalog](sources.md) before using it as a reference.

- For AO3 stories, use the work's own **Download** menu if available; save permitted offline reading copies only in the ignored `downloads/stories/` folder. If the author disabled downloads or access requires an account, leave it as a link and do not bypass the restriction.
- For X posts, bookmark the post. If an offline text-only note is needed, use the browser's Print → Save as PDF while the post is visible. Do not use third-party downloaders for attached art, animation, or audio.
- For Suno tracks or other hosted audio, use the source's own play/share/download controls. Keep the link if no download is offered; don't redistribute a saved track.
- To refresh an entry, reopen the profile and direct post/work, verify whether it still points to the same creator/work, record the new check date, and update the link if the creator has moved it. Add a new row rather than overwriting when an account or work cannot be confidently matched.

No creator profile or work in this directory was individually verified as of the directory date. The handles and category descriptions reflect the user's supplied list; use the source page for current attribution and permission.
