# Local downloaded references

This directory is intentionally excluded from Git. Keep downloaded stories, art, audio, and video here for private research, together with their canonical links and attribution notes. Do not force-add these files to a public commit. The tracked source index is at `../sources.md`.

Subfolders:

- `stories/` — private reading copies where downloading is permitted.
- `images/` — private visual references; record creator, source, and use limits beside each set.
- Add `audio/` or `video/` only when needed, and document source and permission before saving material.
