# Story room

This folder holds story development before material becomes an approved public story or feature script. Keep uncertainty visible: an idea, a working draft, and a locked scene are different states.

## Working stages

- **Seed:** a premise or reference with an unanswered story question.
- **Ideation:** compare scene mechanisms, continuity, character consequences, and alternatives. Cite outside references; do not copy fanwork prose, art, or audio.
- **Working draft:** a playable scene attempt. Mark unresolved placement, dialogue, and characterization directly in the document.
- **Review:** collect story and continuity notes; revise the draft.
- **Locked:** only use after an explicit approval. Link the approved version from the feature script or scene packet.
- **Parked:** retain an idea that is not currently moving forward, with the reason if known.

Nothing in `ideation/` or `drafts/` is an approved feature-script change by itself. Each document should say its current status and link to sources or related material.
