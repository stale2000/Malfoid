# Malfoid

**An anime-style fan project reimagining Draco Malfoy's first year through a new story of rivalry, pride, and unexpected kindness.**

Maintained by [@stale2000](https://github.com/stale2000).

Malfoid is an unofficial Harry Potter fan project. Its long-term creative goal is a complete anime-style reimagining of the first film, with Draco reimagined as a girl and Malfoid given a central story and relationship arc. The work aims for restrained comedy, expressive character acting, and age-appropriate first-year relationships. It is not affiliated with or endorsed by the rights holders.

## What this project is building

The film is planned as linked parts that can be developed, reviewed, and revised scene by scene:

- A story outline, feature script, dialogue, and continuity guide.
- An original anime look, character designs, locations, props, and magic effects.
- Character voice direction, recordings, music, and sound design.
- Storyboards, shot plans, animatics, animation, compositing, and editing.
- Captions, credits, production workflows, and release notes.

The [production plan](docs/production-plan.md) explains how these pieces fit together and how each scene will be tracked. [Source material notes](docs/source-material.md) describe the locally held reference movie; the movie itself is not in this repository.

## Current status

This project is in development. A short anime scene prototype and initial Harry and Draconia voice directions have been developed locally. The prototype has not yet proven a repeatable feature workflow; pronunciation, lip sync, visual consistency, and release terms still need review.

This first public version introduces the project and production structure. It does not include the movie, movie excerpts, soundtrack, screenplay scans, voice samples, fan-reference art, or generated scene videos. Production assets will be added individually when their source, reuse terms, and credits have been recorded.

## Anime direction

The project is developing a shared 2D anime-inspired look for character proportions and expressions, line and color, backgrounds, lighting, camera framing, motion, and magical effects. The style guide will use project-specific designs and examples so the look stays consistent from scene to scene.

## Contributing

Early contributions can help refine the project brief, story and continuity, anime design, scene planning, and production documentation. Do not upload the source movie or its excerpts.
